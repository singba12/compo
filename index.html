Politique de confidentialité – Compo

Dernière mise à jour : 23 février 2026

Compo (« l’Application ») est une application mobile développée par DiofDev (ci‑après « nous », « notre »). Nous accordons une grande importance à la protection de vos données personnelles. Cette politique de confidentialité a pour but de vous informer sur la manière dont nous collectons, utilisons et protégeons les informations lorsque vous utilisez notre application.

1. Données collectées

Nous collectons différents types de données en fonction de votre utilisation de l’application :

  • Données scolaires (locales) : les informations que vous saisissez dans l’application (noms des élèves, prénoms, notes, configurations de classe, etc.) sont stockées uniquement sur votre appareil (via le stockage local du navigateur / localStorage). Nous n’avons pas accès à ces données et elles ne sont jamais transmises à nos serveurs.
  • Identifiant d’appareil (HWID) : lors de l’activation de la version Premium, nous utilisons un identifiant unique généré par votre appareil (Android ID) pour lier votre licence à votre terminal. Cet identifiant est transmis à notre serveur Firebase afin de vérifier la validité du code d’activation et d’éviter toute utilisation frauduleuse.
  • Code d’activation : lorsque vous saisissez un code d’activation, celui-ci est vérifié en temps réel via notre base de données Firebase. Aucune autre information personnelle n’est associée à ce code.
  • Données de connexion : l’application nécessite une connexion Internet uniquement pour la vérification des codes Premium et pour charger certaines ressources (Firebase). Nous ne collectons pas d’adresses IP ni de journaux de navigation.

2. Utilisation des données

Les données collectées sont utilisées exclusivement pour :

  • Activer et gérer votre accès aux fonctionnalités Premium (via Firebase).
  • Améliorer et sécuriser le service (lutte contre les utilisations abusives des codes d’activation).
  • Assurer le bon fonctionnement technique de l’application.

Aucune donnée scolaire ou personnelle (noms, notes) n’est utilisée à des fins commerciales, ni partagée avec des tiers.

3. Partage des données

Nous ne partageons aucune donnée avec des tiers, sauf dans les cas suivants :

  • Firebase (Google) : la vérification des licences s’effectue via Firebase Realtime Database. Seul l’identifiant matériel (HWID) et le code d’activation sont transmis à Google dans le cadre de ce service. Vous pouvez consulter la politique de confidentialité de Google à l’adresse : https://policies.google.com/privacy.
  • Obligation légale : si la loi nous y contraint, nous pouvons être amenés à divulguer certaines informations aux autorités compétentes.

4. Stockage et sécurité

Les données scolaires que vous saisissez restent sur votre appareil. Nous mettons en œuvre des mesures de sécurité raisonnables pour protéger les informations transmises lors de l’activation (chiffrement HTTPS). Cependant, aucune méthode de transmission sur Internet ou de stockage électronique n’est totalement sécurisée. Nous ne pouvons donc pas garantir une sécurité absolue.

5. Vos droits

Vous avez le droit de :

  • Accéder aux données que nous détenons à votre sujet (uniquement l’association code + HWID).
  • Demander la suppression de ces données (en nous contactant).
  • Retirer votre consentement à tout moment (par exemple en désinstallant l’application).

Pour exercer ces droits, veuillez nous contacter à l’adresse ou via les numéros indiqués ci‑dessous.
